Recently added

Three new dashboards, built to work together

One measures whether Copilot is landing. One tracks what it costs. One goes deep on the agents you have built in Copilot Studio. Run any on its own, or together for value, spend and agent quality side by side. Sample data ships with each, so you can look before setting anything up.

New · value & impact

ValueLens

Turns every Copilot and agent signal into hours saved, assisted value, and adoption maturity — a defensible ROI story rather than a seat count. Covers licence readiness for renewals and agent governance for sprawl.

  • Adoption & reach, activity & value, usage maturity
  • Licence readiness — who to reassign, who to keep
  • SharePoint, Fabric and Dataverse paths
Get ValueLens ↗ See the detail →

New · consumption & cost

Consumption Central

One template for Copilot credit consumption and cost across four products — Cowork / Work IQ, Copilot Studio, GitHub Copilot and Azure AI Foundry. Four portals become one view.

  • Group spend by department, cost centre, country, manager
  • Forecast to end of billing period, overage vs prepaid packs
  • Local CSV, Fabric and Viva Direct paths
Get Consumption Central ↗ Cost resources →

New · agent quality

Agent Evaluator

Goes deep on the agents you have actually built in Copilot Studio — what they resolve, what people ask them for, and where the next improvement is. Reads the conversation transcripts themselves, so every number has a real conversation behind it.

  • Resolution and containment, with designed handoffs counted as success
  • Topics, knowledge grounding, CSAT and a ranked fix list
  • Local CSV, Dataverse and Fabric paths — one template
Get Agent Evaluator ↗ See the detail →

Also new

And one for the engineering side of the house

The three above measure Microsoft 365 Copilot and the agents built on Copilot Studio. This one covers GitHub Copilot — the same adoption, depth and value questions, asked of your developers.

New · developer productivity

GitHub Copilot Panel

Asks whether your developers have moved past autocomplete into real delegation — and what that is worth. Seven pages walk one funnel, Licensed → Active → Habitual → Deep → Valued, with every value assumption in one editable table rather than buried in DAX.

  • Engagement depth, not just seats used
  • Value you can defend, with the assumptions on the page
  • Viva Insights GitHub Copilot query, or a local CSV export
