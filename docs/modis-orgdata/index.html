Upload organizational data to Viva Insights via MODIS

A step-by-step reference for getting a customer's organizational (HR) data into Viva Insights and the Copilot Dashboard through the Microsoft 365 Organizational Data Service.

Generated 30 September 2026 · Sourced from Microsoft Learn (current live docs) · Audience: Copilot ROI Advisory Team

Bottom line. "MODIS" is the Microsoft 365 Organizational Data Service (ODS). As of mid-2026 the old Viva Insights web app upload is retired, so org data now enters through the Microsoft 365 admin center. The customer needs the Organizational Data Source Administrator role, a CSV that uses Microsoft_ attribute headers (which auto-map), and required columns Microsoft_PersonEmail, Microsoft_ManagerEmail, and Microsoft_Organization. Validation takes a few hours and up to three days to fully land.

  1. Assign the upload role

    Give whoever uploads the data the Organizational Data Source Administrator role (or Global Admin). Old app-specific Viva roles do not inherit it, so it must be assigned explicitly.

    Entra role reference ↗

  2. Download the CSV template

    In the Microsoft 365 admin center go to Setup › Migration and imports › Microsoft 365 Organizational Data Service, select Get started or New import, choose Start CSV setup, pick the apps to share with (include Viva Insights and the Copilot Dashboard), then Download CSV template.

    Import with a .csv file, Step 1 ↗

  3. Structure the .csv

    One row per employee, UTF-8, up to 2 GB. Use the reserved Microsoft_ headers so columns map automatically. Include all licensed users, ideally everyone. With ODS you do not need the old EffectiveDate column. See the sample and attribute table below.

    Full attribute reference ↗

  4. Import the data

    From Data Connections select New import › Start CSV setup, then choose Import from SharePoint (recommended, and the admin importing must be the same person who uploaded the file) or Import locally. Optionally tick Manually approve data before sharing to review quality first.

    Import steps ↗ · SharePoint upload ↗

  5. Map attributes and set access

    Confirm header mapping and grant per-app attribute access. Using the Microsoft_ prefix skips manual mapping. This is where you decide which apps, such as Viva Insights and Copilot, can read each attribute.

    Map attributes and set access ↗

  6. Validate and confirm

    Select Begin Validation. Data is checked against Viva and Microsoft 365 requirements. Validation takes a few hours, and the full upload can take up to three days to appear in the profile store. Check status on the Organizational data page.

Updates and deletions. To change data, upload a new CSV containing only the affected users. New uploads merge with existing data, they do not overwrite it, and a blank value keeps the previous value. To clear a string value enter three single quotes in Excel or two in the raw .csv. Remove a person by deleting their row in a fresh upload.
