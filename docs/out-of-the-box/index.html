SOURCE 1

Microsoft 365 admin center

admin.microsoft.com → Reports → Usage → Microsoft 365 Copilot. Role required: AI Administrator, Reports Reader, or Global Reader. Data latency is typically ~72 hours.

Foundational windows

Admin Center gives foundational Copilot usage and adoption in standard aggregates: 7 days, 30 days, and 180 days.

Docs ↗

Core reports

Use native Readiness, Usage, Chat, and Agents reports as your first baseline before layering custom segmentation and ROI modeling.

Latency and expectations

These reports are trusted and tenant-native, but they are intentionally high-level and delayed. Treat them as official baseline telemetry.

SOURCE 2

Viva Insights · Copilot analytics

Viva provides richer analytics for adoption patterns, impact analysis, deeper customization, and prebuilt Power BI templates. License required: Viva Insights.

Adoption metrics

User adoption rates and growth trends. Tracks the population curve: licensed → enabled → active → habitual.

Usage patterns

When and how users interact with Copilot — by day of week, by app, by time of day. Surfaces the difference between exploration and ingrained habit.

Productivity impact

The behavior-change layer. Measures the effect of Copilot on focus time, meeting load, after-hours work, and collaboration patterns. The closest native equivalent to Super User Impact.

ROI indicators

Data points to help assess return on investment — not a dollarized calc, but the inputs you need to build one.

Actionable insights

Recommendations engine: which cohorts to nudge, which apps to push, where adoption is stalling. The Dashboard's "what should I do next" panel.

Analyst workbench

Custom Copilot queries · Power BI templates · cross-data analysis · detailed executive reporting. This is the surface most of the Analytics Hub's Viva-based reports (Super Usage, Super Impact) plug into.

SOURCE 3

Copilot Studio analytics

If your org builds custom agents in Copilot Studio, the Power Platform admin center has consumption + performance metrics per agent. This complements (doesn't duplicate) the Admin Center Agents usage report.

Agent adoption and usage

Tracks adoption and consumption per custom agent and per environment to identify where agent value is growing.

Agent performance

Includes quality and performance metrics per agent to support tuning, scaling, and investment decisions.
