# Cowork ROI Model - Changelog

## 2026-10-15
- **Export to PowerPoint (fully client-side).** Added an "Export to PowerPoint" button in the tab bar that builds a formatted 16:9 deck from the current model and downloads it straight from the browser. Nothing is uploaded: the deck is generated with a locally bundled PptxGenJS (`app/lib/pptxgen.bundle.js`, the same file the Usage Tracker uses), with no CDN or network calls. The deck contains a title slide; an executive summary (capacity value and modeled impact side by side, never summed, plus key inputs); time-savings KPIs with an hours-by-category chart; a per-category breakdown table; and, when Annual Revenue is entered, a persona × lever matrix with a chart and one line-item slide per included persona. A methodology and sources slide with hyperlinks closes the deck. Excluded personas and strategies are left out. The file is named after the scenario, e.g. `Contoso-Q3-review_ROI_2026-10-15.pptx`. The privacy disclosure now covers the export.

## 2026-09-18
- **Clickable research links on the Business Impact tab.** Every per-assumption source citation on the Business Impact tab (base and factor rows) is now a hyperlink to the underlying research. A persona-aware `linkifyImpactSrc()` resolves each publisher mention (McKinsey, Forrester, Gartner, Gallup, Mercer, SQM, Bain, BCG, PwC, Deloitte, TSIA, Hackett, BLS, Salesforce) to the exact study cited in the Cowork BVA deck appendix (slides 26-36) using both the citation text and the active persona - so, e.g., "Forrester" maps to the Copilot for Sales TEI in Sales but the D365 Customer Service / Five9 / Field Service TEIs in Customer Service, and "McKinsey" resolves across 11 different articles by topic. Multi-source citations (e.g. "Gallup ... + BLS ...") render one link per source. APQC mentions stay plain text (never hyperlinked in the deck); a deck hyperlink error (a Gallup engagement claim linked to an APQC URL) was corrected to the Gallup Q12 meta-analysis. Verified across all 4 personas: 63 of 138 citation strings linkified, 0 publisher mentions missed. Mapping documented in `Business-Impact-Research-Links.docx`.
- **Clickable research links.** The per-category source citations on the Time Savings tab are now hyperlinks to the underlying research (Stanford-World Bank, McKinsey, Microsoft Research, UK GDS, Cui/CACM, Peng et al., Forrester TEI, Noy & Zhang, NBER, Cambon et al., Microsoft WTI, Brynjolfsson). A `linkifySrc()` helper matches each citation token against a `SRC_LINKS` map (URLs sourced from the Cowork Value Story deck's References slide) and wraps matches in `target=_blank` links. Also added a "References & methodology (research sources)" disclosure listing all 12 sources plus the Cowork Methodology PDF.
- **Import from a Cowork Value Story deck (.pptx) on Tab 1 - now auto-applies.** Added a "Choose PowerPoint" control at the top of the Time Savings tab that reads a Cowork Value Story deck entirely in the browser (no upload) and **automatically applies** what it finds: **credit users (MAU)**, the **task breakdown by category** (mapped to the 8 model buckets), and **credits consumed** converted to a monthly dollar cost via an editable "$ per credit" assumption (default $0.01; editing it re-applies the cost live). The .pptx is parsed with a dependency-free ZIP reader + native `DecompressionStream('deflate-raw')`; category task counts come from the deck's references/methodology table, credit users from the tenant "All users" row, and credits from the "credits" figure. **No confirmation modal appears when all expected data is found** - the values apply silently with a status line. A review panel is shown **only when some expected field is missing**, listing exactly what was not found and suggesting the user enter it manually (found fields are still applied). If nothing at all is found, it shows "No suitable data was found in this deck." Verified against the Pfizer deck: MAU 1,422, credits 6,536,177, all 8 task buckets, assisted hours ~4.5K.

## 2026-09-17
- **P0 credibility fixes (double-counting + labels).** Per formal demo review: (1) The Combined headline no longer adds capacity value + modeled impact into one number. Replaced the single additive grand total with two side-by-side cards — "Estimated capacity value" and "Modeled business impact" — each shown independently and explicitly never summed, with a "do not add them" caption. (2) Relabeled "Measured" -> "Estimated" everywhere (card badge, title, total row, main intro) and reframed capacity as "estimated capacity value derived from usage" rather than a measured result. (3) Renamed the "ROI multiple" as **Net Benefit/Cost** = (benefits - costs) / costs (Tab 1 KPI card and both Combined headline cards), and changed the Tab 1 `roi()` calc from benefit/cost to (benefit-cost)/cost. (4) Labeled the all-persona matrix total and combined modeled scope as **upper bound** to flag cross-persona overlap / potential double counting.
- **Removed hard company-size numbers from assumption sources.** Stripped `$5B`-based figures and derived dollar amounts (e.g. "~$390M at $5B") from the source sub-headers so they don't contradict the user-entered revenue; kept unit rates and %-of-revenue framing. Renamed the reset button "Reset assumptions to BVA defaults" -> "Reset to defaults".
- **Sample Cowork workflows per strategy.** Added a "Examples" button on every strategy row (Business Impact tab) that expands an inline panel with 2-3 concrete sample use cases showing how Cowork applies to that scenario. Content lives in a `WORKFLOWS` map keyed by persona + KPI (27 strategies x 3 workflows); the panel toggles independently of the calculation view.
- **Combined ROI card now aggregates all personas.** The "Business impact" card and combined grand total / blended ROI now sum across all included personas (portfolio view) instead of only the selected persona, matching the matrix "All personas" total. Label shows "(all N personas)" or "(X of N personas)" when some are excluded.
- **Combined ROI: strategy & persona nullify controls.** Added a reversible `disabled` flag on strategies and personas. Each strategy row (Business Impact tab) has an "Exclude / Include" toggle; a per-persona "Exclude this persona" button sits next to Reset. `lineValue()` returns 0 for a disabled strategy and `personaTotals()` returns zeros for a disabled persona, so exclusions propagate to the KPI cards, goal totals, Combined matrix, grand total and blended ROI. Excluded items render struck-through at `$0`; "Reset assumptions to BVA defaults" clears all exclusions.
- **Combined ROI: all-persona x lever matrix.** Added a table on the Combined page showing every persona (Sales, Finance, Marketing, Customer Service) across all three levers (Revenue growth / Reduce cost / Manage risk) with per-persona totals and an "All personas" portfolio total row. Rows are clickable to select the persona; the active/excluded persona is highlighted. Scales live with Annual Revenue.
- **Annual Revenue input left blank on load.** Removed the default `5,000,000,000` value so users enter their own figure. Added a `e.g. 5,000,000,000` placeholder and changed the helper text / echo to read "Enter your annual revenue to begin" until a value is entered. All modeled values display `$0` until a revenue is provided (handled by existing `parseRevenue`).
