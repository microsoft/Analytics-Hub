Privacy note and how to verify network behavior

Data handling: This ROI model runs fully in your browser. Inputs and calculations stay local to your session and are not posted to any API by this page.

Clarity: This page does not include a Microsoft Clarity script, so input data is not sent to Clarity from this app.

How to verify: Open browser DevTools then Network. Enable Preserve log. Filter by Fetch/XHR, then refresh and edit fields in the model. You should see no new API calls tied to your edits. You can also filter for clarity.ms; this page should show no matching requests.

Reading the two numbers: The measured value is the labor time Cowork gives back, observed from your own usage. The modeled value is what the business could realize if that recaptured capacity - plus in-task quality, faster ramp, and better work composition - is redirected into the outcomes on Tab 2.

Avoid double counting: The two views overlap conceptually (modeled impact is one way the measured capacity gets spent). Treat the measured value as the floor you can defend from usage data, and the modeled value as the upside case, rather than simply adding both for a single headline figure.
