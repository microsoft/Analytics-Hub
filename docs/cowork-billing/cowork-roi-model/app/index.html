Privacy note and how to verify network behavior

Data handling: This ROI model runs fully in your browser. Inputs and calculations stay local to your session and are not posted to any API by this page.

Clarity: This page does not include a Microsoft Clarity script, so input data is not sent to Clarity from this app.

PowerPoint export: "Export to PowerPoint" builds the .pptx entirely in your browser using a locally bundled copy of PptxGenJS (lib/pptxgen.bundle.js, no CDN) and saves it straight to your device. Nothing is uploaded.

How to verify: Open browser DevTools then Network. Enable Preserve log. Filter by Fetch/XHR, then refresh and edit fields in the model. You should see no new API calls tied to your edits. You can also filter for clarity.ms; this page should show no matching requests.

Reading the two numbers: The estimated capacity value is the labor time Cowork gives back, valued from your usage x assumed minutes saved x labor rate. The modeled value is what the business could realize if that recaptured capacity - plus in-task quality, faster ramp, and better work composition - is redirected into the outcomes on Tab 2.

Avoid double counting: The two views overlap (modeled impact is one way the estimated capacity gets spent), so they are shown side by side and are not added. Treat the estimated capacity value as the conservative view you can defend from usage, and the modeled value as the upside case. Net Benefit/Cost = (benefits - costs) / costs, using the annual Copilot credit + license cost from Tab 1.
