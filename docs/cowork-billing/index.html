How credit limits actually behave

The two limits in a spending policy enforce very differently. This trips up most conversations, so it is worth being precise — and it explains why a user capped at 20,000 credits can still finish a task at 32,000.

Hard cap

Policy-level budget

The overall monthly credit limit on the spending policy. This one really stops.

“When users hit the limit, they lose access to agents and services for the rest of the month until credits reset on the first of the month.”

This is the number to manage if you need spend to stop at a figure you can commit to.

Soft limit

Per-user spending limit

The per-person allowance inside a policy. It does not hard-stop a running task.

“If a running task exceeds the per-user limit, it can complete without interruption. The excess usage doesn’t count toward the policy limit, isn’t billed (at Microsoft’s sole discretion), and doesn’t appear as consumed credits in the Cost Management dashboards.”

So per-user overage is currently absorbed by Microsoft, not billed to you — and because it never appears as consumed credits, you cannot reconstruct it from the export.

Both quotations are verbatim from Microsoft’s Managing AI experiences enabled by usage-based billing, last updated 13 August 2026. Note the qualifier “at Microsoft’s sole discretion” — this is current behaviour, not a contractual guarantee, and it can change. Treat any overage figure in these tools as a planning estimate; full-consumption figures are unaffected. Your Microsoft invoice remains the record of truth.

Where do I get these files?

Each browser app above runs on two CSV exports you already own — nothing is uploaded, everything is parsed locally in your browser:

  1. Entra user export(s) — in the Microsoft Entra admin center, open Identity → Users → All users and choose Download users. This CSV carries the org attributes (Department, Cost Center, Job title, etc.) used to allocate cost and group people.
  2. Copilot credit / Cost Management export — in the Microsoft 365 admin center, go to Copilot → Cost management → Consumption and choose Export CSV. It just needs one row per user with the credits they consumed.

Column names are auto-detected, so most export layouts work as-is. The Power BI report & template uses the same two sources.
