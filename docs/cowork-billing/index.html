Credit consumption & cost

What Copilot costs, where it goes, and who to bill.

Templates, browser tools and methodology for tracking Microsoft Copilot credit consumption and cost — from a single view of spend across products, through to departmental chargeback and spend policy.

New · Power BI template

Consumption Central

One template for Copilot credit consumption and cost across four products — Cowork / Work IQ, Copilot Studio, GitHub Copilot and Azure AI Foundry. Today that is four portals and four exports with no single view.

  • Group spend by your own org data — department, cost centre, country, manager
  • Forecast to the end of the billing period, with overage and unused capacity against prepaid packs
  • Three deployment paths — local CSV, Fabric, or straight from Viva
  • Synthetic sample data ships with it — see the whole report before touching a tenant

It reports; it does not enforce. Limits and policies stay in the admin centre — this tells you what they should be.

Cowork Credit Chargeback

Turns Cowork credit consumption into a departmental bill, from the Microsoft 365 admin center export plus your Entra user list, or live from Viva Insights with no exports at all.

  • Live from Viva Insights (Direct Query): a self-refreshing variant that connects straight to Viva, supports scheduled refresh, and needs no CSV exports
  • Three billing models priced side by side — pay-as-you-go, prepaid, hybrid, with the cheapest flagged
  • Prepaid pool allocation — split by usage, by headcount, or by budgeted allowance
  • Per-user limits and an over-limit watchlist — who needs their allowance adjusted
  • Row-level security — department heads see only their own line
  • FOCUS cost view — the chargeback in FinOps Open Cost & Usage Specification columns

Analytics Hub · FinOps-Cowork

Not sure which one? Chargeback and the FinOps report run on the same data. Chargeback answers “bill this department.” FinOps answers “show Cowork next to our other cloud spend.” If the customer already has a FinOps practice, start with FinOps. If they just need to bill departments, start with Chargeback. Policy Helper is the follow-up either way: Chargeback tells you what already happened, Policy Helper stops it happening again.

Where do I get these files?

Each browser app above runs on two CSV exports you already own — nothing is uploaded, everything is parsed locally in your browser:

  1. Entra user export(s) — in the Microsoft Entra admin center, open Identity → Users → All users and choose Download users. This CSV carries the org attributes (Department, Cost Center, Job title, etc.) used to allocate cost and group people.
  2. Copilot credit / Cost Management export — in the Microsoft 365 admin center, go to Copilot → Cost management → Consumption and choose Export CSV. It just needs one row per user with the credits they consumed.

Column names are auto-detected, so most export layouts work as-is. The Power BI report & template uses the same two sources.
