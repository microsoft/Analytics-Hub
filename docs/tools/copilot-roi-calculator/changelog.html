v31 Latest September 8, 2026
Improvements
  • The Viva Insights person query is now the only supported upload format — it is the only export with per-person weekly rows, which true Usage Threshold cohorts require
  • Super Usage Report heatmap exports are no longer accepted; uploading one now shows on-screen guidance naming the format and the three required columns (PersonId, MetricDate, Total Copilot actions taken)
  • Step 1 rewritten as a single Viva Insights export path — the two Power BI heatmap options have been removed
  • Demo dataset switched to Viva Insights data (300 people, 7 organizations, 14 weeks), so the demo now shows real Power/Habitual/Novice/Low/Non-user cohorts instead of approximated percentile buckets
  • sample-data.csv replaced with a Viva Insights person-query example
