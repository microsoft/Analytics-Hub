Set up delivery once

  1. Email, in any Outlook. Go to Power Automate, create a flow from blank, and pick the RSS trigger When a feed item is published. Paste the address above, then add the Outlook action Send an email (V2) addressed to yourself. Both connectors are included with Microsoft 365, so there is nothing to buy. This lands in your normal inbox and works in new Outlook, Outlook on the web and on your phone.
  2. A Teams channel. Open the channel, select More options (…) beside the channel name, then Workflows. Search for webfeed and choose Post to a channel when a webfeed item is published. Paste the address when prompted.
  3. Classic Outlook only. File → Account Settings → Account Settings → RSS Feeds → New. This is the built-in RSS reader, and it exists only in classic Outlook. New Outlook and Outlook on the web cannot do it, so use option 1 instead.
  4. Any feed reader. Paste the address above.

20 August 2026 Multi-Budget Chargeback Report

Prepaid settlement, entitlement templates and a Post to GL export

AddedFixed

Re-bills each organisation against the share of the prepaid pool it funded, so consumption order stops deciding who gets the discounted rate. Entitlements load from a downloadable template, by CSV, or pasted from Excel, and the report says exactly what matched. Surplus can be redistributed, rebated or held centrally. Post to GL exports one row per unit, ready for Apptio. Per-unit amounts now add up to the invoice to the cent, and the workbook export handles 200,000 users in about eight seconds.

17 August 2026 Cowork Policy Helper

Policy Helper v1.2 — numbered tiers and a roster-first layout

ChangedFixed

Policy tiers are numbered Tier 1, Tier 2, Tier 3 rather than named, which reads more easily against real spending policies. The user roster now opens the report, since it is the working surface. Changing a rate or editing a tier allowance refreshes the change-impact bar, roster and exception queue immediately.
